# Fraud Detection in Transactions

## Project Description
This project is a Java Swing-based desktop application that identifies suspicious transactions using sample fraud detection rules.

## Technologies Used
- Java
- Java Swing
- AWT
- File Handling
- Multithreading

## Features
- Customer name and account number validation
- High-value transaction detection
- Unusual transaction amount detection
- Repeated transaction detection
- Account ownership validation
- Transaction history storage
- Transaction status display

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Compile the Java files.
4. Run the FraudDetectionApp class.

## Project Type
Java Desktop Application using Swing.
